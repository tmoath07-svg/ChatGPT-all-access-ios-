# GTA Converter

تطبيق iOS بواجهة عربية لتجهيز ملفات مودات GTA V وتحضير ملفات الإخراج لـ PS4.

## الحالة
- المشروع قيد التطوير.
- الواجهة المستهدفة عربية RTL.
- الميزات المخطط لها: استيراد ZIP، فحص الملفات، إنشاء dlclist.xml، وتجهيز حزم الإخراج.
- تحويل أصول المودات فعلياً يحتاج دمج محرك تحويل متوافق؛ لا يُعتبر التحويل مدعوماً قبل دمجه واختباره.
