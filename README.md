# GTA Converter

تطبيق iOS عربي لتجهيز ملفات مودات GTA V على iPhone.

## طرق الاستيراد
- اختيار ملفات ZIP وRAR من تطبيق «الملفات».
- اختيار مجلد كامل من تطبيق «الملفات».
- تنزيل ملف ZIP أو RAR من رابط HTTP/HTTPS مباشر.

## مكتبة المودات والمتصفح (1.5.0)
- متصفح داخلي ببحث مصنف لمودات المركبات والخرائط والشخصيات.
- اختصارات مباشرة للتصنيفات المدعومة، مع تقييد التصفح داخل هذه التصنيفات.
- التقاط روابط ZIP وRAR المباشرة من صفحات المودات المدعومة وتنزيلها إلى `GTA Converter/Mods`.
- شاشة تنزيلات تعرض التقدم والحالة وتحفظ سجل التنزيلات محلياً.
- مكتبة تعرض ملفات Mods وImports وReady، وسجل نشاط لتجهيز الملفات وتنزيلها وإنشاء حزم Orbx.
- تخصيص لون الواجهة والخلفية، واختيار صورة خلفية من الصور، وتشغيل أو إيقاف تأثير Motion Blur عند فتح صفحات الأدوات.
- الأيقونة الأساسية تُنشأ في وقت البناء بالنص `GTAV MODS` واسم المنشئ بالبرتقالي. تبديل الأيقونة من داخل التطبيق غير مفعّل في هذه النسخة.

ملاحظات المتصفح: التنزيل يعتمد على أن يقدّم الموقع رابط ZIP أو RAR مباشراً. المواقع التي تتطلب تسجيل دخول أو روابط تنزيل خاصة قد لا تعمل، ولا يتم تجاوز حماية المواقع.

## تجهيز الملفات
- فك الأرشيف إلى مجلد عمل مستقل.
- الاحتفاظ بالملف الأصلي دون تعديله.
- منع مسارات الأرشيف غير الآمنة (مثل ../) أثناء الفك.
- مشاركة مجلد الناتج إلى تطبيق «الملفات» أو أي تطبيق يدعم المشاركة.
- إنشاء dlclist.xml بصيغة Orbx المطلقة:
  `/data/orbx/gta/rpf/dlc_addon/NAME/`

## متطلبات البناء
- XcodeGen
- Swift Package: libarchive-for-swift 1.0.0 (SwiftArchive)
- iOS 16.0 أو أحدث
- Bundle ID: `com.tmoath07.gta-converter`

## حدود النسخة
- يدعم فك أرشيفات ZIP وRAR عبر libarchive، لكن يجب اختبار الأرشيفات الكبيرة أو المشفرة على الجهاز الفعلي.
- الرابط المباشر يجب أن يكون رابط تنزيل فعلياً ينتهي بملف ZIP أو RAR، وليس صفحة ويب تتطلب تسجيل دخول.
- التطبيق يفك وينظم الملفات ويجهز XML؛ لا يحوّل أصول مودات PC إلى صيغة PS4 تلقائياً ولا يثبتها على جهاز PS4.
- بناء GitHub Actions الحالي غير موقّع. يلزم توقيعه بحساب/شهادة Apple صالحة قبل تثبيته.
