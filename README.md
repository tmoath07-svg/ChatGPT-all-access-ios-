# INRPF 3.30

تطبيق iOS عربي لتحليل وتجهيز **مودات مركبات GTA V وموارد مركبات FiveM** محلياً على iPhone وiPad.

## الإصدار 3.30 — Build 34

- محرك Rust محلي مدمج داخل التطبيق عبر C ABI.
- تحليل بنية ملفات المركبات المدعومة وقراءة بيانات Handling وXML.
- مقارنة مجلدين باستخدام SHA-256 مع كشف الملفات المضافة والمحذوفة والمتغيرة.
- فحص أرشيفات RPF الخاصة بحزم المركبات وعرض ملفات META المعروفة فقط؛ استخراج الأرشيف كاملاً غير متاح.
- معاينة هندسية ثلاثية الأبعاد لبعض ملفات مركبات YFT وYDR وYDD المدعومة.
- استخراج خامات YTD إلى DDS ضمن الصيغ المدعومة.
- مكتبة مودات محلية وسجل عمليات وقوالب مشاريع.
- أدوات PDF ونسخ احتياطي وفحص اعتماديات موارد المركبات.
- ذكاء اصطناعي محلي مضمّن: Qwen2.5 1.5B Instruct Q4_K_M عبر llama.cpp، دون API أو خادم أثناء التشغيل.
- فحص SHA-256 لملف النموذج أثناء البناء.
- FTP إلى Orbx مع فحص مسبق لحزم المركبات ونسخ dlclist.xml احتياطياً والتحقق بعد الرفع.
- لا تُرفع ملفات المستخدم إلى خادم عند استعمال أدوات التحليل والمعالجة المحلية.

## حدود التوافق مع PS4

فك YTD إلى DDS لا يساوي إنشاء OTD. وبناء RPF7 لا يساوي تحويل موارد GTA V إلى صيغة PS4. ما زال إنشاء OTD بصيغة Orbis وتجميع DLC متوافق بالكامل مع PS4 قيد النقل والاختبار. لا تعتبر أي حزمة صالحة لجهاز PS4 حتى تنجح اختبارات بنية الموارد ثم اختبارها داخل اللعبة.

## الذكاء الاصطناعي المحلي

- النموذج: Qwen2.5 1.5B Instruct GGUF، تكميم Q4_K_M.
- الحجم التقريبي: 1.12GB.
- الترخيص: Apache-2.0، مرفق في `GTAConverter/Resources/Qwen-LICENSE.txt`.
- محرك التشغيل: SwiftLlama / llama.cpp داخل التطبيق.
- يحتاج اتصالاً أثناء بناء IPA لتنزيل ملف النموذج والتحقق من بصمته؛ بعد تثبيت التطبيق يعمل الاستدلال دون إنترنت أو سيرفر.

## طرق الاستيراد

- اختيار ملفات ZIP وRAR من تطبيق «الملفات».
- اختيار مجلد كامل من تطبيق «الملفات».
- تنزيل ملف ZIP أو RAR من رابط HTTP/HTTPS مباشر.

## تجهيز الملفات

- فك الأرشيف إلى مجلد عمل مستقل.
- الاحتفاظ بالملف الأصلي دون تعديله.
- منع مسارات الأرشيف غير الآمنة أثناء الفك.
- إنشاء dlclist.xml بمسار Orbx المطلق:
  `/data/orbx/gta/rpf/dlc_addon/NAME/`

## متطلبات البناء

- XcodeGen وXcode حديث يدعم Swift 6.1 أو أحدث.
- Swift Package: libarchive-for-swift 1.0.0 (SwiftArchive).
- Swift Package: swift-llama-cpp (نسخة مثبتة على revision محدد).
- Rust stable مع target `aarch64-apple-ios`.
- iOS 17.0 أو أحدث.
- Bundle ID: `com.tmoath07.gta-converter`.

## FTP

- تجربة EPSV أولاً ثم PASV للتوافق مع خوادم FTP.
- استخدام عنوان اتصال التحكم نفسه لاتصال البيانات عند PASV.
- إنهاء تدفق رفع الملف بإشارة EOF قبل انتظار رد نجاح الخادم.
- الرجوع من MLSD إلى LIST عند عدم دعم MLSD.
- التحقق من حزم المركبات محلياً قبل بدء الرفع.
- التحقق من dlclist.xml بعد الرفع.
- توافق FTP النهائي يعتمد على اختبار فعلي مع إصدار Orbx/GoldHEN المستخدم.
